# بورتفوليو أحمد هيبة — تعليمات النشر والتعديل

## الملفات
- `index.html` — الصفحة كاملة (التصميم والمحتوى في ملف واحد)
- `photo.jpg` — صورتك الشخصية (مقصوصة من سكرين شوت لينكد إن، يفضل تستبدلها بالأصلية بنفس الاسم)
- `CV.pdf` — لازم ترفعه بنفس الاسم ده عشان زرار "Download CV" يشتغل

## خطوات النشر على GitHub Pages
1. من حسابك https://github.com/ahmedhiyba11 اعمل repository جديد اسمه بالظبط: `ahmedhiyba11.github.io` وخليه **Public**.
2. جوه الـ repo اضغط **Add file ← Upload files** وارفع: `index.html` و `photo.jpg` و `CV.pdf`.
3. اضغط **Commit changes**.
4. روح **Settings ← Pages** واختار Branch: `main` و Folder: `/ (root)` واضغط **Save**.
5. بعد دقيقة أو اتنين الموقع هيبقى شغال على: **https://ahmedhiyba11.github.io**

اللينك ده حطه في لينكد إن (Contact info ← Website) وفي أول الـ CV.

## اللي لازم تكمّله بنفسك
1. **لينكات الداشبوردات**: كل مشروع فيه `<a href="#">Open dashboard</a>` — بدّل الـ `#` بلينك الـ repo على GitHub أو الفيز على Tableau Public.
2. **صور الداشبوردات**: دي أهم حاجة هتفرق. صوّر كل داشبورد PNG، ارفع الصور في نفس المجلد، وحط السطر ده جوه `<div class="body">` بتاع المشروع:
   ```html
   <img src="churn.png" alt="Churn dashboard" style="width:100%;border:1px solid var(--line);border-radius:4px;margin:14px 0">
   ```
3. **راجع الأرقام**: كتبت الأرقام زي ما هي في وصف مشاريعك على لينكد إن. لو فيه رقم اتغير عدّله.
4. **الشهادات**: لو عايز كل شهادة تبقى لينك مباشر، افتح الشهادة على Credly/Coursera وانسخ اللينك.
